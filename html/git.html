Основные команды Git

  • git init – расшифровывается как "initialize", что переводится как "инициализировать". Создаёт новый локальный репозиторий в текущей папке.
  • git add – расшифровывается как "add", что переводится как "добавить". Добавляет изменения в отслеживаемые файлы (подготовка к коммиту).
  • git commit – расшифровывается как "commit", что переводится как "зафиксировать". Сохраняет добавленные изменения в истории репозитория.
  • git status – расшифровывается как "status", что переводится как "состояние". Показывает текущее состояние рабочей директории и индекса.
  • git log – расшифровывается как "log", что переводится как "журнал". Выводит историю коммитов.
  • git branch – расшифровывается как "branch", что переводится как "ветка". Показывает список веток или создаёт новую ветку.
  • git checkout – расшифровывается как "check out", что переводится как "переключиться". Переключается между ветками или восстанавливает файлы.
  • git merge – расшифровывается как "merge", что переводится как "слияние". Объединяет изменения из одной ветки в текущую.
  • git clone – расшифровывается как "clone", что переводится как "клонировать". Копирует удалённый репозиторий на локальный компьютер.
  • git push – расшифровывается как "push", что переводится как "отправить". Загружает локальные коммиты в удалённый репозиторий.
  • git pull – расшифровывается как "pull", что переводится как "вытянуть". Забирает изменения из удалённого репозитория и сливает с текущей веткой.
